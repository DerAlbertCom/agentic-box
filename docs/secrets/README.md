# Secrets of the kits

One page per service the kits of this repository ask for. `abox secrets init`, `abox
secrets update` and `abox create` link to these pages from the guided secrets setup:
a kit names the page in the `docs` key of its `secrets.yaml`. How the guided setup works
is in [the CLI reference](../cli-reference.md#abox-secrets); how a kit declares its
secrets is in [authoring secrets](../authoring-secrets.md).

| Service | Page |
| --- | --- |
| `abox-github-enterprise` | [GitHub Enterprise token](../github-enterprise-token.md) |
| `abox-github-copilot` | [GitHub Copilot token](github-copilot.md) |
| `abox-azure-devops` | [Azure DevOps](azure-devops.md) |
| `abox-jfrog` | [JFrog](jfrog.md) |
| `abox-cape-elastic`, `abox-mod-elastic-nprod`, `abox-mod-elastic-prod`, `abox-predictopus-elastic` | [Elastic](elastic.md) |
| `abox-cape-database-mcp` | [CAPE database MCP](cape-database-mcp.md) |
| `abox-aws-bedrock` | [Amazon Bedrock](aws-bedrock.md) |
| `abox-context7` | [Context7](context7.md) |
